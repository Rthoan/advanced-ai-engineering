========================================
FINAL PRINCIPLES
========================================

Keep endpoints thin.

Business logic belongs in services.

Database models are not API contracts.

Authorization must be deterministic.

Never retry write operations blindly.

Long-running jobs should not block HTTP.

Production APIs need explicit boundaries.
