# Return Policy

## Return Window

Customers may request a return within 30 days after the order has been delivered.

## Eligibility

To be eligible for a return:

- The order must have been delivered.
- The return request must be submitted within 30 days of delivery.
- The order must not already have an active return request.

## Damaged Items

If an item arrives damaged, the customer may request a return using the return workflow.

## Unsupported Cases

If the available policy documents do not contain enough information to answer a question, the assistant must not invent a policy.
