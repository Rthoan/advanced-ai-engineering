Day 03 — Architecture Decision Examples

====================================
1. TEXT TRANSLATION
====================================

Requirement:
Translate English text to Arabic.

Solution:
LLM

Architecture:

User
↓
LLM
↓
Translated Text


====================================
2. COMPANY DOCUMENT SEARCH
====================================

Requirement:
Answer questions from 20,000 company documents.

Solution:
RAG

Architecture:

Question
↓
Embedding
↓
Vector Search
↓
Relevant Chunks
↓
LLM
↓
Answer

====================================
6. RETURN WORKFLOW
====================================

Requirement:
Check order
↓
Check return policy
↓
Check eligibility
↓
Create return
↓
Retry on failure
↓
Request approval when required

Solution:
LangGraph

Architecture:

Start
↓
Order Tool
↓
RAG Tool
↓
Eligibility Check
↓
Eligible?
├── No → Explain
└── Yes
     ↓
Return Tool
     ↓
Failed?
├── Yes → Retry
└── No
     ↓
Approval Required?
├── Yes → Human Approval
└── No → Complete
