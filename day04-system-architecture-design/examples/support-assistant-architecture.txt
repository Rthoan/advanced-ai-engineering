Day 04 — Support Assistant Architecture

========================================
PROJECT
========================================

AI Support Assistant

Features:
- Answer company policy questions
- Show ticket status
- Create a new ticket
- Escalate to human support
- Send confirmation email

========================================

========================================
FAILURE CASES
========================================

Authentication failed
→ 401 Unauthorized

Ticket belongs to another user
→ 403 Forbidden

Ticket not found
→ 404 Not Found

Ticket Database unavailable
→ 503 Service Unavailable

RAG finds no reliable context
→ Do not hallucinate
→ Escalate to human support

LLM timeout
→ Retry / Fallback

Email fails after ticket creation
→ Keep ticket created
→ Retry email
→ Log failure


========================================
LLM REQUIRED
========================================

- Generate answers from RAG context
- Intent classification when needed
- Natural-language response generation


========================================
LLM NOT REQUIRED
========================================

- Authentication
- Validation
- Ticket lookup
- Ownership check
- Ticket creation
- Database access
- Email sending
