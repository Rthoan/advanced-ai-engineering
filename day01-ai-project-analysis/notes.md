# Day 01 Notes

## Important Rules

General generation
→ LLM

Private documents
→ RAG

Actions / APIs / external tools
→ Agent

Documents + Actions
→ RAG + Agent

---

## Tool

A Tool performs or retrieves something external.

Examples:

- Email Tool
- Database Tool
- Order API Tool
- Calendar Tool

---

## LLM

The LLM is mainly responsible for:

- Understanding
- Reasoning
- Classification
- Generation
- Summarization

---

## RAG

RAG retrieves relevant knowledge before asking the LLM to answer.

---

## Agent

The Agent decides which tool or workflow should be used.

---

## Project Analysis Checklist

1. Who are the users?
2. What problem are we solving?
3. What are the inputs?
4. What outputs are required?
5. What are the data sources?
6. How much data exists?
7. Does the data change?
8. Do we need an LLM?
9. Do we need RAG?
10. Do we need an Agent?
11. Do we need external tools?
12. What are the security requirements?
13. What are the latency requirements?
14. What are the cost constraints?
15. How will we evaluate success?
