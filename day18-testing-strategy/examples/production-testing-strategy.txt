========================================
FINAL PRINCIPLES
========================================

Test the lowest reliable layer.

Do not mock everything.

Test edge cases.

Test failure paths.

Every bug becomes a regression test.

Critical security failures block deployment.

Test how the system breaks,
not only how it works.
